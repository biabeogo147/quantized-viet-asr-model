# Completed Plans

This directory contains closed implementation plans whose tasks, canonical-documentation updates, and required verification gates all passed.

Each completed plan must retain its original options, decision rationale, checked task list, progress log, verification evidence, canonical docs updated, and repository update notes. Completed plans are historical records; update them only to correct factual errors or broken links, not to redefine current behavior.

Use the canonical documents linked from the root README for current pipeline behavior.
