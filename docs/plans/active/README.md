# Active Plans

This directory contains only implementation plans for work that still has unfinished tasks or required verification.

- Create plans from `../TEMPLATE.md` after read-only discovery and before any other tracked change.
- Update task checkboxes and the progress log immediately after each task passes its verification gate.
- Keep blocked plans here with the blocker and required next action recorded.
- Move a plan to `../completed/` only after every task, canonical-doc update, and plan-level verification gate passes.

If this directory contains only this README, no tracked implementation work is currently active.
